1.0 Introduction  
 
This Best Practices is a fabricated tool to install camshaft bearing on Caterpillar 3500 series 
engines.  It can install one entire bank of bearings at the same time.  It is adaptable to handle 
3508, 3512, and 3516 engines. 
The tool significantly reduces the time required to install camshaft bearings and improves 
technician safety compared to other manual installation methods.
