1.0 Introduction  
 
Material, consumable and tool management strategy is critical to CRC operations. In order to 
achieve high and consistent productivity in a shop, the tools, materials and consumables must be 
handled in an efficient way. The effective management can be achieved by using ToolWatch 
software. ToolWatch Enterprise software is one of the most comprehensive systems available 
today for managing tools, equipment, materials and consumables more efficiently across the 
company. 
The key success factors in CRC are to minimize unplanned failures of tools and equipment and 
efficient management of consumables and materials. Proper control and monitoring saves time, 
reduces lost and failures of the tools and equipment. When components are repaired or rebuilt at 
the dealer CRC, dealers must be able to assess the current inventory level of consumables and 
materials, condition of the equipment and tools. These assessments can be performed with 
ToolWatch, which can generate over one hundred reports such as: consumable usage report, 
material and consumable low level report, lost/broken tools report, calibration schedules, tools by 
employee and etc., instantly. 
 
 
2.0 Best Practice Description 
 
This Best Practice contains several standard reports from ToolWatch used in Borusan Makina 
Kazakhstan Company in order to achieve efficient control and monitoring of tools, equipment, 
materials and consumables. 
 
Consumable usage report  
 
ToolWatch generates a report which shows the quantity and the price of consumables and 
materials for the selected or all work order for a selected period. The report includes:  
• Description of consumables/materials 
• Price for consumables/materials 
• Quantity of used consumables/materials 
• Item number consumables/materials 
• Work Order/location/employee (of consumed material ) 
          A sample report is attached. This report was generated using ToolWatch software.

Broken/Lost tools report  
This report generates a report with broken/lost tools of any selected employee. Also a quantity 
and price of broken/lost tools in entire company can be assessed. 
 
Current inventory report   
 
This report shows the quantity and the price of consumables and materials in any selected stock. 
The report includes: 
• Description of consumables/materials 
• Price for consumables/materials 
• Quantity of consumables/materials 
• Item number consumables/materials 
• Place where the consumables/materials can be found  
 
 
Low level report   
This report shows a list of consumables which are below of defined low level. A sample report is 
attached. This report was generated using ToolWatch software.

3.0 Implementation Steps 
 
1. Determine level of dealer interest in using such  management strategy and software 
2. Purchase ToolWatch Enterprise software 
3. Train Tool Keepers for using ToolWatch 
4. Implement materials, consumables and tools into ToolWatch 
5. Decide what kind of reports will be used 
6. Efficient control and monitor the tools equipmen t, consumables and materials 
 
 
 
 
4.0 Benefits 
 
• Saving Time (Purchase Order, stock, used) 
• Efficient Control and Monitoring of tools (Calibr ation, Service) 
• Efficient Control and Monitoring of materials (in  stock, used, low, target and high levels) 
• Excellent tracking system (reduced loss, status c ontrol)  
• Over 100 Reports can be generated instantly 
• Maintains updated Tools and Materials Inventory 
• Effective management of the inventory 
 
 
5.0 Resources Required 
 
Personnel time to create and manage report system and process.
