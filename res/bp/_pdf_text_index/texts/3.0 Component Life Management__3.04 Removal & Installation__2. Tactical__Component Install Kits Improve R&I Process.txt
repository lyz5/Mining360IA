1.0 Introduction  
 
Proper installation of major components into a machine can have substantial impact on 
component life and reliability. A high quality installation procedure requires a well-defined process 
utilizing the right tools, parts, and readily available technical information. 
 
This Best Practices discusses the use of standardized component installation “kits” that include 
all parts, control checklists, and other technical information required to perform a major 
component installation. 
 
Standardized install kits help insure that component installations are performed in a consistent, 
efficient, high quality manner to deliver optimum component life.

2.0 Best Practice Description 
 
Many dealers, working with their customers, have jointly developed a standardized component 
installation process along with a required parts Bill of Materials  (RBOM) for the installation.  The 
required Bill of Materials is often delivered in the form of a “kit”, which can either be shipped along 
with the component from the dealer shop or assembled on the mine site.   
 
The important benefit of this Best Practice is that everything needed to perform a job 
professionally and efficiently is staged with the component when a major component is installed 
in a machine. 
 
    
  
 
3.0 Implementation Steps 
 
There are typically two parts of a component installation kit. The first is a Required Bill of 
Materials kit containing all the parts required to perform the component installation. The second is 
a literature package containing checklists, technical information, and other required forms and 
documents. 
 
Bill of Materials 
Every component installation requires some parts. Caterpillar R & I checklists list many of these 
required parts.  Typically, parts include standard as well as break-in High Efficiency fluid filters, 
mounts and mount hardware, air intake system seals, coolant system hoses and clamps, drive 
shaft bolts, or any other required hardware. 
 
In addition, many dealers customize the installation parts kits to meet specific customer needs as 
related to machine application or customer preference.  Many customers, for example, want to 
change all compartment fluid hoses whenever a component is removed as standard practice.

The best way to manage installation Bill of Materials is to develop a spreadsheet organized by 
machine model and arrangement.  Each component would then have a specific list of parts for 
the installation. In this way, the parts list is created one time and used every time a component 
matching the model an arrangement is rebuilt. Once the list is developed, the dealer should 
ensure part numbers remain current.

Information Package 
 
A typical information package for a component installation includes: 
• Caterpillar R & I Checklist (See Attachments for index and checklists) 
• R & I Special Instructions 
• Oil Sample Kit 
• Forms required for the installation record keeping and component tracking.
