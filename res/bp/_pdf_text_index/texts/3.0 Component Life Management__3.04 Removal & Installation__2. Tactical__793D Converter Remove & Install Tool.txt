1.0 Introduction  
Currently the tools for removal and installation of the 793D OHT Torque Converter are chains and 
eyebolts (Fig. 1). These tools were designed for high safety, but we felt we have improved upon 
the process. 
 
This document shows a tool (preliminary design) for the converter removal and installation more 
safely and quickly. 
 
 
 
 
Figure 1.  SIS procedure for the Converter removal

The tool consists of three bent and welded plates as shown in Figure 2.

3.0 Implementation Steps  
 
Steps for Removal 
1. Refer to document RENR8328-05 Torque converter Removal. 
2. Clean the bolt holes on the converter top  
3. Attach the removal tool (1) to torque converter (6 ) using 5/8 – 11 x 2.50 UNC Bolt (2), 5/8 
– 11 x 3.25 UNC (3), and two 5/8 washers (4). Tighten bolts to 60 N·m (see figure 4) 
4. Attach  the screw pin shackle (5) to straight slot in R&I tool 
5. Attach appropriate overhead lifting device of minimum 2 ton capacity to raise and support 
the tool with the converter (The weight of torque converter is approximately 1043 kg). 
 
Steps for Install   
1. Clean the bolt holes on the converter top  
2. Attach the removal tool (1) to torque converter (6) using 5/8 – 11 x 2.50 UNC Bolt (2), 5/8 
– 11 x 3.25 UNC (3), and two 5/8 washers (4). Tighten bolts to 60 N·m (see figure 4) 
3. Attach  Screw Pin Shackle (5) to circular hole in R&I tool 
4. Attach appropriate overhead lifting device to raise and support the tool with the convert.  
5. Continue with the guide RENR8328-05 Torque converter Install  for install the other 
components

housing.  This also helps keep things more level.
