MINING DEALER BEST PRACTICE  
 
1.0 Introduction  
The lifting devices used for the removal and installation of components in the equipment must 
provide protection to the personnel and machine. The technicians in a shop don´t always have a 
specific tool and use some general methods for the removal of components. The Converter for 
the D11R is an example of this. Such a component is removed by using two ratchet pullers, link 
brackets, and slings (Figure 1).   
 
This Best Practice describes the design of a tool to remove the D11R/T torque converter in a 
more secure and fast for technicians. 
 
                 
 
 
 
  
 
2.0 Best Practice Description  
The tool consists of a curved plate to be adjusted to the converter geometry. The dimensions can 
be found attached to the drawings (See Figure 4).

3.0 Implementation Steps 
 
Steps for removal 
1. Refer to the SENR 1782-08 Manual (D11R Torque Converter Removal) or the Manual KENR 
5620-00 (D11T Torque Converter Removal), and follow the steps before installing the tool. 
2. Locate the tool to the converter using two 5/8” bolts – 11 x 1.75” UNC (grade 8) with their 
washers. The minimum torque value for the bolts is 30 N·m. 
3. The converter is removed with a lifting device with a minimum lifting capacity of 550 kg. The 
weight of the torque converter is approximately 366 kg. 
Steps for the Installation 
1. Install converter tool with bolts and washers listed above (minimum torque value 30 N·m ) 
2. Refer to the Installation Manual SENR 1782-08 (D11R Torque Converter Installation) or to the 
Manual KENR 5620-00 (D11T Torque Converter Installation). 
 
 
The tool can be used in the followings converters (D11R and D11T series) 
 
 
 
 
 
 
 
 
 
1 Some  D11T models use this converter 
 
4.0 Benefits 
The tool has the following advantages: 
• Reduced assembly time. 
• A faster converter removal process when reducing the possibilities of contacting the fan pilot 
pump, not using slings (See Figure 1). 
• Lower cost of the tool. See Comparative table 2 and 3.
