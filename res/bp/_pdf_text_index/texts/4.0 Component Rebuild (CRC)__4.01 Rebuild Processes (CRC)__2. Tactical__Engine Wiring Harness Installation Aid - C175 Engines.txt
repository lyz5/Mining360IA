1. Introduction  
 
The engine wiring harness groups have a large number of small parts used in its installation.  
Matco has implemented a process to aid in the installation of the engine wiring harnesses on 
C175 engines.  Installation of these harnesses was found to be challenging and time consuming, 
and a more visible guide was desired to aid the assemblers.   
 
2. Best Practice Description 
 
This Best Practice uses a print of each of the main engine wiring groups.  Each print is printed on 
a large background using a plotter-type printer.  They are then displayed temporarily in the 
assembly bay while the harnesses are being installed.  The assembler then has a very clear, 3-D 
image of the harnesses and all their connectors, as well as a storage location for each part.

It is suggested that the prints are affixed to plexiglass for protection, and to enable simple edits 
with a marker as needed.   
 
 
 
3. Implementation Steps 
 
• Send email to Gallagher_William_L@cat.com requesting, by part number, the engine wiring 
group.   
• Set up a cabinet of drawers with the required spare parts, divided and labelled appropriately 
with part number, location code, and quantity per engine.  
• Open the prints in Microsoft Paint and add the location codes next to each part.  
• Make large print-outs that can be referenced easily during installation of the harnesses.  
   
4. Benefits 
 
• Organized, easily and quickly retrieved parts.  
• Clear visual representation greatly improve installation process efficiency. 
• Reduced time to install C175-20 wiring harnesses from 48 man hours to 6 man hours. 
 
5. Resources Required 
 
• Suitable parts cabinet w/ drawers and dividers 
• Resource to set up and label cabinet, and to designate cabinet locations on the print 
• Process to restock as necessary
