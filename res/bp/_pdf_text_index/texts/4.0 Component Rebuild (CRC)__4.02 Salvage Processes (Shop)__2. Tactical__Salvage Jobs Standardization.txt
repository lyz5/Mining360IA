1.0 Introduction  
 
Borusan Makina Kazakhstan has implemented Repair Drawing in the Machine Shop to 
standardize salvage operations.  
 
Previously, every time the component came in for salvage, the machine operator spent a lot of 
time searching for information in SIS (for specifications), plus send a request for the drawing 
required and wait for it. Besides, it created a number of problems like unclear repair 
requirements, lack of quality control, no repair history, no salvage time planning. 
 
The implementation of Repair drawing has reduced pre-salvage time, standardized salvage 
operations, improved the quality control and allowed to keep the repair history and plan the 
salvage operation time.  
 
 
2.0 Best Practice Description 
 
Repair Drawing combines component salvage specifications and drawing in one document. It 
consists of four main parts: 
 
I  -  General information about the component with Repair Drawing No,  
i.e. W/O No, Component name, Machine Model, Part No and Qty. 
 
II  -  Component salvage specification with the time allocated per each operation, 
i.e. Operation No, Damage Description, Dimensions before Salvage, Standard 
Operation Name & Description (or how the defect will be fixed), Material, Procedure & 
Tools (recommended to use), Technician Name, Planned Time, Actual Time. 
 
III -  Quality Control field with the place for sticker of QC Passed, 
 
IV -  Drawing.

3.0 Implementation Steps 
 
In order to prepare Repair Drawing the following steps should be done: 
• Determine the defect of the component (usually it is done during the inspection) 
• Find the procedure that will fix the defect in the SIS 
• Divide by operations in the Repair Drawing template 
• Complete all columns of the Repair Drawing template except the columns indicating 
dimensions before salvage, technician name and actual time spent for each operations 
• Attach the drawing that was taken from the SIS or DSN inquiry 
• Give the ready Repair Drawing the operator (the operator will complete the rest columns) 
• Collect the Repair Drawing after the salvage operations is finished 
• Keep the Repair Drawing for the Repair History 
 
4.0 Benefits 
 
• Reduced pre-salvage time (there is no need to search for specs and drawings) 
• Standardized salvage / repair operations 
• Improved Quality Control 
• Repair History are kept 
• Improved planning time for component savage 
 
5.0 Resources Required 
 
• A Qualified Service Engineer with enough engineering experience and a SIS user. 
• Laptop & printer with A4 Paper.

6.0 Supporting Attachments / References 
 
EDITOR’S NOTE:  Upon review, Caterpillar has the following recommendations to go with this 
Best Practice: 
• Recommend establishing some sort of dating system on the prints, so they know when the 
print was current.   
• Recommend establishing a print maintenance program, with the technical svc's group, to 
assure any changes are installed into their prints, as they are announced through Svc 
Magazines, or other update publications. 
• This would parallel any other product update maintenance programs the dealer has for 
their major component rebuild control documents. 
• Recommend dealer building their salvage standard jobs with their traditional standard job 
system (that they use for rebuilding major components) if possible, instead of this Best 
Practice (different) system.
