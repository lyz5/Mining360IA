1.0 Introduction  
 
Due to the lack of a tool for the correct centering of the steering cylinder sensor, a device was 
designed and manufactured to avoid damage to the sensor stem. 
 
2.0 Best Practice Description 
 
This improvement consists of a disc to keep the sensor centered in the cylinder and a holder to fix the 
sensor during piston assembly. 
 
To use this tool, you need to perform the following steps: 
 
 
1. Install the bar (without adjusting it) to be able to adjust the distance.
