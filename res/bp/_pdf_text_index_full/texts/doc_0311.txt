1.0 Introduction  
 
This upgrade improves safety and provides an ergonomically improved method for rod 
measurements using Mahr Connecting Rod Bend and Twist Measurement 
       System -DFM050918-1. 
 
 
2.0 Best Practice Description 
 
This upgrading method uses a pneumatic system for positioning the rod on the Mahr Connecting 
Rod Bend and Twist Measurement System -DFM050918-1.  
Procedure: 
1. Check the vertical and horizontal movements of the pneumatic system. 
2. Put the connecting rod on the base and move it vertically to locate the rod and then move 
it horizontally to the measuring equipment (Mahr Connecting Rod Bend and Twist 
Measurement System -DFM050918-1). 
3. Evaluate and record the measurement. 
Remove the connecting rod using the horizontal and vertical base. 
 
3.0 Implementation Steps 
 
a) Design of the pneumatic system for handling connecting rod

measurement process in the Mahr Rod Bend and Twist Measurement System tool -
