1.0 Introduction  
  
Accurate and proper Preventative Maintenance is crucial to maximizing machine life.  
 
Currently, there is no way to generate a Preventative Maintenance (PM) checklist from the PM 
Checklist Website that displays each PM task, along with the associated parts list for each PM 
task, displayed together within the same document. Using the BUILDER Checklist Utility, a PM 
Checklist that shows the parts needed for each task can be generated. 
 
The most efficient and comprehensive checklist is available in the BUILDER Checklist Utility 
using available CGM BUILDER files posted to CatMiner since 1/01/2006 (and all future CGM 
BUILDER files) or the dealer’s own localized versions of these files.  These files use a ‘Job 
Operation’ PM structure, which is necessary for the PM Checklist Utility to function. 
 
Note:  PM Checklists for Mining equipment posted to the CatMiner 'BUILDER Downloads' 
webpage prior to 1/1/06 can be downloaded from the CatMiner 'Legacy PM Checklist' webpage at 
https://catminer.cat.com/cda/layout?m=117964&x=7

4.0 Benefits 
 
1. Dealers that currently us e their own localized CGM BUILDER files can generate a PM 
checklist that reflects any changes they have made to the PM Repair Options within their 
BUILDER files.   
2. Elimination of the need for a dealer to make these same changes to a PM checklist 
downloaded from the PM Checklist Website. 
3. Both PM tasks and associated parts lists ar e displayed together within the same document. 
This provides a simpler, clearer format to follow for conducting PM routines.
