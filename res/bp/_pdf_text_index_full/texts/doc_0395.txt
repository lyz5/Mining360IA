1.0 Introduction  
 
Live Work: Any task (i.e. testing, commissioning or troubleshooting) that requires the system to 
be energized and the person to enter the footprint of the machine (excludes doing the same task 
from the machine cabin or outside the machine footprint). 
 
This “Elimination of Live Work (ELW) Procedure” replaces the corresponding description in the 
HMS machine documentation. The intention of the procedure is to eliminate live work by 
removing the technician from the area of the machine to reduce possible hazard of injury while 
inspecting or maintaining the machine. 
This procedure provides the information to measure the tilting play of the swing gear. The tilting 
play must be measured at machine commissioning and used as a reference to measure increase 
of play. 
This procedure can be done using Cat Multitool GP to eliminate the risk of proximity to the 
machine.

2.0 Best Practice Description 
 
This applies when checking the HMS slew ring tilting play for all machine listed below.  
 
 
 
Important Safety Information  
 
Operators and maintenance personnel should be protected in the best possible way while  
working on the machine. Therefore, all work should only be carried out (if not described  
differently): 
 not with and on running engines / motor 
 not while the machine is moving 
 not with moving work equipment 
 not under raised work equipment 
 not on systems under pressure 
 not on components that are too hot to be touched by hand with gloves.

3.0 Implementation Steps 
 
Tools Required:                                                             
 
 
 
 
 
Job Preparation:  
 
1. Isolate the machine before positioning the 
Tool GP on it. 
2. Allow only authorized people to perform the 
job procedures. 
3. Job needs 3 people to perform it (Operator, 
Spotter, and Inspector). 
4. Ensure that all slew ring bolts are tightened as 
described in the Service Manual. 
 
Job Procedure: 
 
1. Assemble Tool GP (576-0855). 
2. Assemble magnet tool (1) to Stud (3). 
3. Assemble stud (3) to swivel post snug (6). 
4. Assemble sensor to swivel post snug (6), after magnet tool (1) is located into position on 
the slew ring.

   Ring by holding the magnet tool against the  
   slew ring component then turn the handle

counterclockwise 180 degrees activates the magnet

free of debris.

6. Adjust the locations of the measurement tool group, adjust the location of stud using the slotted 
hole on the bracket, or change the sensor tip using the 6V-6042 Indicator Point GP to ensure that the 
sensor tip is against the component.
