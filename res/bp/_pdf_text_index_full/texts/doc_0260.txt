1.0 Introduction  
 
There is no Caterpillar tool to rotate a 3500 series engine crankshaft in a short block when the 
engine front and rear covers are no installed.  It is necessary to turn the crankshaft in order to 
install the connecting rods.  This Best Practice is a dealer fabricated tool to rotate the crankshaft.  
The tool also locks into position so the crankshaft does not move while the connecting rod bolts 
are torqued. 
 
2.0 Best Practice Description    
                                   
This Best Practice has been implemented by Ferreyros.     
 
                                 
 
 
This tool makes it easy to rotate the crankshaft to any desired position and then lock the 
crankshaft in place.  This makes the installation of connecting rods easier and assures that the 
crankshaft will not slip during the connecting rod bolt torque process.
