1.0 Introduction  
 
A new tool which improves the deburring of the top deck surface in engine block 3500 has been 
implemented at the machining workshop in Ferreyros S.A. The tool is a Lessmann nylon abrasive 
bristle disc. 
 
 
2.0 Best Practice Description 
 
Previously, the deburring process of top deck surface was a manual process using rasps and 
hand deburring tools. It took three hours approximately.  The new process using an abrasive 
bristle disc (See the picture 1) has reduced the top deck surface deburring time by 90% (15 
minutes approximately). In addition, manual deburring was performed using three technicians, but 
now requires only one. 
 
 
 
Picture 1. Abrasive bristle disc

The brand and specifications of the abrasive bristle disc are shown below: 
 
• Trademark: LESSMANN. 
• Code: 405.850 - Abrasive nylon SIC K 120 x 0,6mm. 
• Dimensions: 400 x 25 mm 
• Trim: 25 mm 
• Bore: 50 mm 
 
 
3.0 Implementation Steps 
 
 
• After machining the top deck surface, install an abrasive bristle disc on the milling machine 
(Rottler F99Y in this case - See the picture 2). 
 
 
 
 
Picture 2. Abrasive bristle disc installed.
