1.0 Introduction  
Accurate, up-to-date parts lists within Dealers’ BUILDER files are crucial in developing and 
maintaining MARCs, Standard Jobs, and PM Checklists. 
 
Currently, there is no automated process within the BUILDER software to update the BUILDER 
parts lists with ‘Cancelled - Replaced By’ (CRB) parts. A tool in the form of an Excel macro was 
developed by the MPSD Equipment Management Services group that automatically replaces 
and/or identifies the CRB parts in BUILDER from DBS or DBSi. 
 
There are three different scenarios in which CRB parts are addressed: 
1) When one part is cancelled and replaced by one part (‘one-for-one’), 
2) When many parts are replaced by one part (‘many-for-one’), or 
3) When one part is replaced with many parts (‘one-for-many’). 
 
This tool automatically replaces the CRB parts in a ‘one-for-one’ or a ‘many-for-one’ scenario in 
the selected BUILDER database. It creates a grief report to address each ‘one-for-many’ 
scenario. In this situation, the macro will automatically add the new parts (the ‘for-many’ parts) to 
the Master Parts Table in BUILDER, but the user will have to manually add the ‘for-many’ parts in 
each applicable job parts list and delete the cancelled part. Before replacing the part numbers in 
BUILDER, the spreadsheet has an option to view the dealer on-hand quantities of the cancelled 
parts. 
 
2.0 Best Practice Description 
 
To Set-Up Client Access ODBC:  
 
1. Click Windows 'Start' button.  
2. Click 'Settings'.  
3. Click 'Control Panel'.  
4. Click 'Administrative Tools'.  
5. Click 'Data Sources (ODBC).  
6. On the 'User DSN' tab, click the 'Add' button. 
7. Select 'Client Access ODBC' driver and click 'Finish' (Note: If the Client Access ODBC driver is  
missing, it can be loaded from the dealer’s CD labeled “AS400 Client Access Family for  
Windows" or install Client Access Express).  
8. Type in a Data Source Name (i.e. CATS6R).  
9. Enter your AS/400 System Name (i.e. CATS6R.SC.CAT.COM).  
10. Click 'OK' to save connection. 
 
To perform the update: 
 
1. Copy the spreadsheet into the folder where the BUILDER database is stored.  
Note: see attachment in Section 6.0 in this document to download the spreadsheet. 
2. Enter the ODBC name that points to the AS/400.  
3. Enter the data library that contains the PIC Store (PCPPIST0) file, which contains store on-

1. Import current parts pricing after performing ‘Engineering Design Change Part Update’. (The
