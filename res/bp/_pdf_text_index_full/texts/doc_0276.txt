1.0 Introduction  
During the D11 Track roller frame removal and installation process, it is necessary to use some 
tools in order to ensure a safe procedure. This process is referenced in the document 
SENR1782-08 or RENR8226-03 for one frame and it should be applied in the same way for the 
second one. However, the document does not mention another component that should be 
blocked during the removal of the two track roller frames which is the pivot shaft. 
 
This Best Practice describes the tool which allows to block the pivot shaft and keep its centered 
position on the main frame during the removal and installation process of the two track roller 
frames. 
 
2.0 Best Practice Description 
During the two track rollers frames removal and installation process, it is necessary to block the 
pivot shaft to keep it from moving freely alongside the hole in the main frame. When removing a 
singer roller frame, it is not necessary to do this because the other track roller frame restricts the 
pivot shaft movement (See figure 1).

3.0 Implementation Steps 
 
Steps for track roller frame Removal: 
1. Refer to disassembly document SENR1782-08 (D11R Track Roller Frame Removal) or 
RENR8226-03 (D11T Track Roller Frame Removal) and follow the steps to remove one track 
roller frame. 
2. Place neoprene piece on pivot shaft face. 
3. Locate the tool securing it with two bolts and washers to the pivot shaft. The bolts used 
depend on the pivot shaft (see Table 2), which minimum torque is 25 N • m. The closest final 
drive should be between the two support plates, place a wooden block to adjust it to the tool 
(See Figure 3 and 4) 
4. Once the pivot shaft is secured; continue with the removal of the other track roller frame as 
indicated on SENR1782-08 or RENR8226-03 
 
Steps for the track roller frames Installation: 
Follow the steps above using the installation document SENR1782-08 or RENR8226-03.

4.0 Benefits 
• Improved safety during pivot shaft removal and installation process to prevent it from going 
out and cause damage or harm to the technicians. 
• It maintains the horizontal position (centered) the component must have. 
• It decreases time and component handling complexity.
