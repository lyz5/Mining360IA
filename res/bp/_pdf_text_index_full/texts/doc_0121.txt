1.0 Introduction  
 
This Best Practice illustrates the use of VIMSTM data for managing payloads in an application 
where 992G Wheel Loaders were required to deliver precise payloads. 
 
Application background: 
• Iron Ore loaded onto train cars for 
transport via public rail network 
• Mining contractor responsible for 
loading the train cars. 
 
This practice was developed when the 
contractor approached the Caterpillar Dealer 
to find a payload system that would address 
the following:  
• Rail wagon axle loadings are critical to 
the public railway. 
• Maximum payload critical for client. 
• Validation that wagons loaded 
correctly by the Contractor 
 
Precision payloads would rely upon VIMS functioning and reporting correctly, subsequently 
leading to:  
• Lower cost per ton, by delivering maximum payloads to the Port. 
• Eliminate overloading of the wagon /axles. 
• Correct payload in wagons to maximize revenue for customer

2.0 Best Practice Description 
 
VIMS would be utilized for acquiring key payload data, as it was already on the 992G Wheel 
Loaders. Although, originally it did not report total truck weight, so Caterpillar changed the VIMS 
report and machine configuration file to enable this feature. 
 
1. Every train loaded has an ID number (i.e. “7625”) and every wagon used to transport the ore, 
displays a “wagon ID” which was painted on the wagons by the railway company.  
 
• The Wagon ID numbering system 
has been categorized by target 
payload (for example: #100 to 
#200 would have a target weight 
of 68 tons; and #201 - #300 would 
have a target weight of 66 tons).  
 
 
 
 
 
 
 
 
 
 
 
 
 
2. The train number is entered when the 
train stops. This number is entered into 
the “BLAST NUMBER” field.  
 
3. The 992G operator begins to load the 
train, and after the first bucket, is 
prompted to enter the wagon ID (which 
is painted on the side of the ore wagon).

4. VIMS prompts the operator to select the 
Material ID for loading “fines” or “lump” onto 
the train.  
 
5. The operator will load two full buckets, take a 
payload reading, and adjust the third and final 
load accordingly, to match the target payload 
of the wagon. 
 
 
 
 
 
 
 
 
6. After the shift is complete and the machine is parked, the payload data is uploaded via 
wireless link directly into a program (provided by the dealer) on an office computer. Summary 
reports are generated to analyze payloads by train ID.  
 
7. The total payload (tons) loaded, is verified by the Client when unloading at the port. Both the 
VIMS report and Client report are then reconciled. If excessive variation is discovered in each 
wagon, the operator will complete additional training on the payload system. 
 
The VIMS payload reporting system is accurate, and a report confirms the payload weight 
variance on every wagon. (See next page).

3.0 Implementation Steps 
 
1. Client paints the wagon ID numbers onto the 
ore wagons. 
2. Dealer relocates keypad to enable easy 
operator input into VIMSTM.   
3. Dealer creates Train Loading Report Program 
to verify actual wagon payloads. 
4. Caterpillar had to change the report files and 
configuration files in the 992G loader system 
5. Contractor has a master test weight fabricated 
and certified. 
6. Dealer and contractor set-up VIMS
TM. and 
trained 992G operators. 
 
 
4.0 Benefits 
 
1. Train weight-to-Port weight is verified and accurate. 
2. The axle loadings are checked and wagon loads verified. 
3. The Customer has maximum payload railed to the Port. (One-half a ton short/ wagon could 
result in a potential revenue loss of $7 million) 
4. Correct axle weights reduce risk to the customer (in the case of a derailment). 
5. Correct payload in wagons maximizes revenue for customer. 
 
 
5.0 Resources Required 
 
1. Client paints wagon ID numbers to wagons    - $5,000 
2. Dealer made report program. (No charge)    - $       0 
3. Contractor fabricates calibration weight & validates.   - $7,000 
4. Dealer relocates VIMS key pad      - $1,000 
5. Dealer conducts site training. (No charge)    - $       0 
 
       TOTAL   - $13,000
