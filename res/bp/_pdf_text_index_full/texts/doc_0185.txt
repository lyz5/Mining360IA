1.0 Introduction  
 
In our workshop, technicians need to able to verify the assembly and operation of an alternator and 
starting motor after an overhauling motor. Testing allows the dealer to ensure that the alternator and 
starting motor will operate properly on the machine.  Rotation of an alternator and starting motor 
provides the most conclusive evaluation. 
 
Most electronic control modules and electronic monitors work with the same strategy. Sometimes it is 
not possible to find some ECM and monitor failures on the machine. Some customers bring the ECM 
and monitor to the workshop in order to check and get information. 
 
The alternator, starting motor and ECM testing bench has been designed to test and find faults for 
reduced cost. The bench also provides opportunities for training.  
 
2.0 Best Practice Description 
 
The alternator, starting motor, and ECM test bench is designed to do the final test of the alternator 
and starting motor after an overhaul. Also this bench provides testing and flashing of all kind of ECM 
and monitors for the technician.  
 
The Alternator and starting bench capabilities are as following: 
 Able to measure current and voltage of alternator 
 Able to measure voltage at R terminal 
 Able to measure speed of alternator 
 Able to measure current and voltage of starting motor 
 Able to measure voltage on the solenoid 
The ECM test bench capabilities are as following: 
 Able to connect to all type of ECMs 
 Able to test all type of monitoring systems 
 Able to flash and load configuration to various ECM

4.0 Benefits 
 
 
 
The following alternator and starting motor tests can be performed on this bench. 
 
1) Perform an alternator output test 24V/12V on the bench 
2) Perform a regulator test  on the bench 
3) Perform starter test on the bench 
4) Perform  no-load starter test on the bench 
 
The following monitoring and ECM tests can be performed on this bench. 
 
1) Test monitoring system input components 
2) Test monitoring system output components 
3) Test monitoring system display panel  
4) Test monitoring system input processor 
5) Test ECM for input and output component 
6) Use Cat ET to perform flash programing 
7) Use Cat ET to perform factory password 
8) Use Cat ET to perform copy configuration and replace
