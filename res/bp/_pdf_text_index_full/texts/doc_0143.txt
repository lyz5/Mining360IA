1.0 Introduction  
Component Life Cycle Analysis (CLCA) is a process developed with the intent of analyzing component lives, 
with specific focus on the following objectives: 
Determining realistic component replacement intervals in order to project prudent Parts Cost Variables 
(PCV) forecasts for commercial purposes.  
 
To identify which components failed prematurely in order to assist in the identification of technical 
issues and life determining factors. 
 
 
2.0 Best Practice Description 
 
2.1 Period of analysis 
Information gathered is actual component life performance data for the last three (3) years to date 
and / or contract term to date, with analysis frequency recorded quarterly.  
2.2 Analysis Procedure 
 
2.2.1 Weibull analysis -  (Median Rank Regression X on Y – RRY Method)  
This method is used to depict the component projection life for commercial purposes with 
consideration to both types of data, being change-out and suspend data.  
The limitation of this method is that it is not able to generate results from a small amount of data 
(less than 10 change-out data), In this case, use the current projection as the result. 
The result from this RRY analysis will be B50 (Probability time to change -out for 50% population

rolling occurrences to identify the actual performance of the components and plot onto a trending

values produced by the Weibull from t he primary analysis. The source and outline criteria shall be 
filtered as required producing trend comparisons (see figure 2 below) 
The Results for the projection life calculations use an average of the last 10 occurrences and the average

2.3.1 Component Interval Projection 
Upon analysis of this data, the recommended projection will then be calculated using the average of 
all calculated results and then rounded to the next lowest multiple of 500 hours 
The projection life spreadsheet will be containing the complete formula for this policy.

The purpose of this action is to calculate the next future occurrence that will impact from applying 
the current and recommended projection.

The result of the above analysis will be compiled into report called “Component Life Cycle Analysis 
Report”.

3.0 Implementation Steps 
 
3.1   CLCA  
CLCA is a periodic analysis, requiring accurate data for use as a reference for future strategy 
implementation and financial reporting. Therefore it may be necessary that the raw data supplied 
should be validated from site management prior to distribution. 
3.2   Data Cleansing 
The initial data cleansing (removal of data where double ups of Work Order (WO) number & other 
common data errors), and loading of accurate component history is a one-time exercise, but is 
absolutely essential. The amount of labor required to cleanse (remove errors) from the data, is 
dependent on the number of components being tracked and the quality of component history records 
itself.  
3.3   Maintenance Strategy Reference (MSR)   
 In conjunction with the MSR, the result of this analysis will be used as input for next MSR review. 
AMT life cycle projection hours will be updated once a year in conjunction with the budget & MSR 
(If the quarterly data shows an exceptional differential then the forecast may be reviewed 
immediately in a controlled manner if authorized by the relevant manager)

4.0 Benefits 
 
4.1 Prudent Parts Cost Variable (PCV) Forecast 
Availability of a standard process used to determine component change out intervals 
Ability to identify occurrences and financial impact on component change out interval  
4.2 Component early failure indicators 
This factor can be analyzed utilizing rolling average data and beta # (trend) of Weibull analysis 
4.3 Maintenance Practice Indicators 
This factor can be analyzed utilizing rolling average data and beta # (trend) of Weibull analysis 
4.4 Application and Operations Indicators  
This factor can be analyzed utilizing rolling average data and beta # (trend) of Weibull analysis 
4.5 Strategy Input 
By CLCA report information, it will help equipment management planning across sites to allow 
improved decision making in terms of stra tegy improvement (i.e. Interval replacement changes, 
repair option selection and also component’s source) 
 
 
5.0 Resources Required 
 
The main engine of this analysis is the understanding of using Weibull statistics method and able to 
used as Life Data Analysis Tools. For this reason, it is important to install related application as our 
main tools to produce analysis (i.e. Reliasoft Weibull++, Minitab, etc). Joint the training session 
from software vendor it is gives more values for Component Analyst to enhance his/her ability to 
optimize Weibull analysis on Reliability engineering. 
 
The report is produced using Microsoft Excel, with development looking to be completed to make 
all calculations automatically integrated within available Weibull software. 
 
The Main source of raw data is in AMT system, and there are web-based tools to import data based 
on specific filter and cleansing, thus reducing errors caused by human data entry.
