1.0 Introduction  
 
Many Trakindo branches overhaul engines and some technicians have found it difficult to install the 
crankshaft.   This can affect the efficiency of the installation, expose the component to potential 
damage, and reduce cleanliness and safety.  To improve the crankshaft installation, Trakindo has 
created a standard operating procedure to install the crankshaft using guide blocks. 
 
 
2.0 Best Practice Description 
 
Many times when installing a crankshaft to a cylinder block, it will collide with the cylinder block. This 
Best Practice helps the technician avoid the potential collision when using the proper lifting equipment 
for this installation.   The guide blocks presented in this document assist in guiding crankshaft’s main 
journals into the blocks main bearing.

3.0 Implementation Steps 
 
- Fabricate the Guide Block from solid rubber or po lyurethane.  
- Integrate use of the Guide Blocks into the standa rd operating procedure. 
o Install the guide blocks after the upper half of t he main bearings are installed. 
o Assure shaft is handled with crane and appropriate  strap/chain/fixture. 
- Train employees to use the new procedures/equipme nt. 
- Review process/equipment performance once establi shed. 
 
4.0 Benefits 
 
Safety and Installation Time 
- Well designed/organized installation will improve  the time to install and safety. 
 
Quality 
- Guide blocks allow crankshaft installation with l ittle or no journal denting opportunities.   
- A more effective/simplified installation process will promote higher technician professionalism, 
higher standards, and increased brand image.
