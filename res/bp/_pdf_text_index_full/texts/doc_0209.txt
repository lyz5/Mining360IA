1.0 Introduction  
 
Caterpillar has changed the retainer ring for the transmission control spool valves. This new ring-
retaining (Part number: 383-7597) is stronger, but the installation of this ring is more difficult. This 
Best Practice is a simple tool that facilitates the installation of the retainer ring while using the 
Caterpillar tool (Part number: 446-5933). 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
2.0 Best Practice Description 
 
Ferreyros has developed a simple tool that compresses the spring spool, giving enough space for 
the installation of the retainer ring.
