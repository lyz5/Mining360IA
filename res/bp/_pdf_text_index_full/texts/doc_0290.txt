1. Introduction  
In the C175 models, the KENR6052 assembly manual indicates that the valve  guides are 
installed one at a time  in the cylinder head. This is done by using the valve guide driver 283-
0052 and a suitable hammer . The proposed  tool described in this best practice has been 
designed to install the 4 valve guides simultaneously , while still keeping installation efforts to 
a minimum. 
 
2. Best Practice Description 
This tool will be able to install all 4 valve guides all at once, thus decreasing the time to 
complete the task. It also makes the task more efficient and easier to complete. To install, the 
guides must be centered on the cylinder head, and an appropriate press must be used to 
install the valve guides themselves. Implementation steps and drawings are shown below.
