1.0 Introduction 
I
n iron ore mines, Ground Engaging Tools (GET) represent significant owning costs since wear rates 
are very severe on these operations. As per Caterpillar Handbook of Ripping  (media number 
AEDK0752), a very critical factor on ripper  tip wear rate and ripping production are track type tractor 
ripping operating techniques, specifically referring to shank position during ripping pass.  
Li
terature and best operational practices recommend that  the frame should be parallel to the ground, 
tracks flat on the ground, and shank slightly forward of vertical. In iron ore mines, operational efficiency 
teams have adopted as convention that all  these conditions will be met if ripper tilt cylinder rods are 
60% extended.  
E
ven though these techniques are widely used, it is hard for the operator to visually define this optimum 
cylinder rod extension. The objective of this best practice is  to give the operator an easy -to-see 
reference of this recommended cylinder extension using a rod attached to ripper tilt cylinder heads.  
2
.0 Best Practice Description 
This bes
t practice consists of the production of rod type tools, with length equal to 60% of rod extension, 
design showed in Figure 1, to be fastened to ripper tilt cylinder heads, using its own bolts, as per Figure 
2. Rod length must be changed according to machine model/prefix and/or cylinder PN. Table 1
describes some of the possible lengths for the most common track type tr actor models on mining
applications.

4
.0 Benefits 
I
n the current conditions, basing the cutting angle only on the operator’s perception, ripper tips wear in 
a dome-shaped pattern, as shown in Figure 4. 
Figure 4 - Dome shaped wear pattern 
Using the correct techniques will allow  for more uniform and sharp wear of ripper tips, lowering GET 
cost per hour. The difference is clearly visible when comparing Figure 4 with Figure 5, which shows the 
desirable wear pattern.

Using this reference for operating techniques improvement led to an increase of around 20% of ripper 
tips lifetime. Additionally, to the parts cost savings associated, it represented higher physical availability 
and lower medium time between stops of track type tractors fleet on the tested site.  Correct ripping 
removes the load from the rear idler and reduces track spin, improving undercarriage life.
