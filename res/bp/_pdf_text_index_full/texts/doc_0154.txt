1.0 Introduction  
 
Oil Cleanliness Analysis is one of the primary functions of S·O·STM program. This analysis is 
carried out for 80% of all incoming samples to S·O·STM laboratory. This test determines the 
presence of particles in the oil, which are classified by many symbols. 
Before, we had manually written down all results of this test. Manual Data entry increases the 
time for Oil Cleanliness Analysis. It is double work, when we first write the results on paper and 
then we transfer these same results to S·O·STM Service manager. Using the paper-based 
information makes it inconvenient to keep this information and search for these results. 
 
This Best Practice is aimed to improve the procedures of oil cleanliness analysis with using an 
electronic device. 
 
 
2.0 Best Practice Description 
 
Borusan Makina Kazakhstan has developed the software application which improves the process 
of visual analysis of oils.
