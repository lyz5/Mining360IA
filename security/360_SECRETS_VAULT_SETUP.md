# Coffre de secrets 360

Le coffre de secrets de 360 est un fichier KeePass KDBX chiffré, séparé du code
et de la mémoire documentaire. Il peut être synchronisé avec Dropbox uniquement
après création et après vérification que Dropbox Desktop est opérationnel.

## Création initiale par le propriétaire

1. Dans KeePassXC, créer une nouvelle base nommée `360-Secrets`.
2. Choisir une phrase maîtresse longue, unique et mémorisée par Papa Djibril
   Diagne. Ne pas l'écrire dans ce dépôt, Dropbox, un script ou une conversation.
3. Conserver le fichier sous `Dropbox\360-Recovery\360-Secrets.kdbx` après la
   fin de l'installation Dropbox.
4. Activer les sauvegardes versionnées de la base dans KeePassXC et conserver
   une copie chiffrée hors ligne.
5. Ouvrir le coffre sur une seconde machine ou depuis une copie de test avant
   d'y transférer les accès critiques.

`Mayite`, `DSTV`, `Pacdigitale`, `Marketing Digital` et `MBA`.
